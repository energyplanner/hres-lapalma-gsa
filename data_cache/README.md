# Input data (year 2023)

| File | Content | Source |
|---|---|---|
| `esios_lapalma_d7af5ab7c54a.parquet` | Hourly electricity demand of the La Palma system [MW] | Red Eléctrica (REE), ESIOS indicator 1342, geo_id 8798 |
| `openmeteo_03d7d52f13d8.parquet` | Hourly GHI, DHI, DNI, 2 m air temperature, 10 and 100 m wind speed, pressure at 28.49° N, 17.85° W | Open-Meteo historical weather API (ERA5 reanalysis, Copernicus Climate Change Service) |
| `ninja_wind_raw_850d3bef02eb.parquet` | Hourly wind speed at 80 m at the same location | Renewables.ninja (MERRA-2 reanalysis) |

The file names are cache keys generated by the code from the request parameters, so the
scripts find these files automatically and do not access the internet.

Preprocessing applied by the code: alignment in UTC, linear interpolation of gaps of up to
three hours, removal of 29 February, 8760 hourly values.
